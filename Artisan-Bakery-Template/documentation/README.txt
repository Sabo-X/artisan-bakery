ARTISAN BAKERY WEBSITE TEMPLATE
================================

Thank you for purchasing the Artisan Bakery Website Template.

QUICK START
-----------
1. Open index.html in your web browser.
2. Edit the content using a code editor such as VS Code.
3. Replace the images inside the images folder.
4. Open index.html again to preview your changes.

CHANGING THE BUSINESS NAME
--------------------------
Open index.html and search for "Artisan Bakery".

Replace it with your own business name.

CHANGING IMAGES
---------------
Place your images inside the images folder.

Then update the image filename in index.html.

CHANGING COLORS
---------------
Open css/style.css.

The main colors are defined near the beginning of the file
inside the :root section.

CHANGING TEXT
-------------
Open index.html and replace the existing text with your own
business information.

CHANGING MENU ITEMS AND PRICES
------------------------------
Open index.html and edit the menu names, descriptions and prices.

CONTACT INFORMATION
-------------------
Replace the example phone number, email address and location
with your own business information.

SOCIAL MEDIA LINKS
------------------
Replace the placeholder social media links with your own
social media URLs.

SUPPORT
-------
This is a static HTML/CSS template and does not require a
database or server-side software.
